漏洞名称：
Trendnet TEW-673GRU 1.00B40 /sbin/httpd 请求 URI 解析空指针解引用漏洞

Trendnet TEW-673GRU 1.00B40 是 Trendnet 公司旗下的一款路由器固件，受影响产品为 TEW-673GRU，受影响版本为 1.00B40。

Trendnet TEW-673GRU 1.00B40 的 `/sbin/httpd` 二进制文件中存在一个空指针解引用漏洞。远程攻击者可以通过向设备发送特制的 HTTP POST 请求触发异常 URI 解析流程。当请求路径不包含 `.` 扩展名分隔符时，程序在后续扩展名判断逻辑中对 `strchr()` 返回的空指针直接执行 `+1` 运算并继续解引用，最终导致 `httpd` 进程崩溃，造成拒绝服务。

该漏洞位于二进制文件 `/sbin/httpd` 的请求解析流程中。程序在 `0x407204` 处抽取请求 URI，在 `0x40741c` 处去掉前导 `/` 后将结果作为资源名处理，随后在 `0x407c04` 处调用 `strchr($19, '.')` 查找扩展名分隔符。当请求路径为 `/vct_wan` 时，字符串中不存在 `.`，`strchr()` 返回 `NULL`。程序接着在 `0x407c10` 处将返回值加一，并在 `0x407c20` 处作为参数继续传入后续比较逻辑，最终访问非法地址 `0x1` 并触发 `SIGSEGV`。

攻击者可以远程发起攻击，通过发送类似 `POST /vct_wan HTTP/1.1` 的请求触发漏洞。

漏洞研究环境：

通过模拟仿真进行验证。当前样本目录中提供了对应的请求样本与分析结果，原始固件可通过上述下载链接获取。

通过 greenhouse 进行仿真，greenhouse 链接为 https://github.com/sefcom/greenhouse。相关样本基于当前目录中的运行日志、trace 和崩溃现象完成分析。

目标配置情况：

没有进行特殊配置，默认仿真环境启动。

具体验证过程：

第一步。攻击者向设备发送 `POST /vct_wan HTTP/1.1` 请求。该请求路径不包含扩展名分隔符 `.`，但仍会进入后续的 URI 资源类型判断逻辑。

第二步。程序在 `0x407204` 处解析出 URI，并在 `0x40741c` 处去掉前导 `/` 后得到 `vct_wan`。随后在 `0x407c04` 处调用 `strchr($19, '.')` 查找扩展名，由于目标字符串中不存在 `.`，因此返回值为 `NULL`。

第三步。程序在 `0x407c10` 处将该空指针加一，并在 `0x407c20` 处继续作为参数参与后续比较，最终触发对地址 `0x1` 的非法访问。样本记录中已经出现 `SIGSEGV` 和 `Segmentation fault (core dumped)`，说明该问题可导致远程拒绝服务。
